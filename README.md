# ansible-macos-setup

Ansible playbook for configuring macOS laptops. Currently sets up automated Kopia backups to Backblaze B2, with credentials stored in 1Password.

## Prerequisites

- [Homebrew](https://brew.sh) must be installed
- [1Password](https://1password.com) must be installed with **Settings > Developer > CLI > Integrate with 1Password CLI** enabled
- Two 1Password items are required:
  - One containing Backblaze B2 credentials (access key ID, secret access key, server endpoint, bucket)
  - One containing the Kopia repository password (in the `password` field)

## Setup

Run the bootstrap script, which will prompt for your laptop role, 1Password item names, and then apply the playbook:

```
./bootstrap.sh
```

After setup, grant **Full Disk Access** to the Kopia binary in **System Settings > Privacy & Security > Full Disk Access**:

```
/Applications/KopiaUI.app/Contents/Resources/server/kopia
```

## Re-running after initial setup

Once `bootstrap.sh` has been run, you can re-apply the playbook directly without going through the script again:

```
ansible-playbook playbook.yml
```

Or as a dry run:

```
ansible-playbook -C playbook.yml
```

## Laptop roles

| Role | Description |
|------|-------------|
| `admin_laptop` | Personal/admin machine |
| `family_laptop` | Shared/family machine |

Both roles currently apply the same configuration. The distinction exists for future differentiation.

## What gets configured

- Installs `1password-cli` and `KopiaUI` (Homebrew casks)
- Connects Kopia to a Backblaze B2 repository using credentials from 1Password
- Sets a global Kopia backup policy (zstd compression, ignore lists, never-compress lists)
- Installs a launchd agent (`io.kopia.snapshot`) that runs a full-disk snapshot daily at 02:00
- Logs are written to `~/Library/Logs/kopia/`

## Initializing a new repository

By default the playbook connects to an existing Kopia repository. To initialize a new one instead, set `kopia_repo_action: create` in `roles/common/vars/kopia.yml` before running, then revert it to `connect` afterward.

## Repository structure

```
bootstrap.sh          # Interactive setup script
playbook.yml          # Top-level playbook
requirements.yml      # Ansible collection dependencies
inventory.local       # Generated by bootstrap.sh (gitignored)
roles/
  common/
    tasks/
      main.yml        # Homebrew + package installation
      kopia.yml       # Kopia repo connection and policy
    templates/
      io.kopia.snapshot.plist.j2  # launchd agent plist
    handlers/
      main.yml        # Reload launchd on plist change
    vars/
      main.yml        # Package lists
      kopia.yml       # Kopia configuration
      kopia.local.yml # 1Password item names, generated by bootstrap.sh (gitignored)
```
